============================================================
======= 2. IDENTIFIKASI NODE BERNAMA VS NODE ANONIM ========
============================================================
Contoh pada Potongan 1 (Fungsi):

Node tingkat atas: function_definition (bernama)
Semua children langsung dari function_definition:
  - Child 0: def                    -> ANONIM (tersembunyi)                  | Teks: 'def'
  - Child 1: identifier             -> BERNAMA               [field: name]   | Teks: 'hitung_diskon'
  - Child 2: parameters             -> BERNAMA               [field: parameters] | Teks: '(harga, persen)'
  - Child 3: :                      -> ANONIM (tersembunyi)                  | Teks: ':'
  - Child 4: block                  -> BERNAMA               [field: body]   | Teks: 'return harga * (persen / 100)'

Children di dalam node 'parameters':
  - Child 0: (                      -> ANONIM (tersembunyi) | Teks: '('
  - Child 1: identifier             -> BERNAMA              | Teks: 'harga'
  - Child 2: ,                      -> ANONIM (tersembunyi) | Teks: ','
  - Child 3: identifier             -> BERNAMA              | Teks: 'persen'
  - Child 4: )                      -> ANONIM (tersembunyi) | Teks: ')'

============================================================
======= 4. PERBEDAAN 'children' DAN 'named_children' =======
============================================================
Pada node function_definition:
  - Jumlah total node di children       : 5
    Tipe: ['def', 'identifier', 'parameters', ':', 'block']
  - Jumlah total node di named_children : 3
    Tipe: ['identifier', 'parameters', 'block']

Penjelasan:
- `children`: Mengembalikan semua token konkret dari Concrete Syntax Tree (CST),
  termasuk node anonim seperti keyword 'def', operator, tanda kurung '(', ')', dan titik dua ':'.
- `named_children`: Hanya mengembalikan node yang berasal dari named rule di grammar tree-sitter,
  yaitu node yang memiliki identitas semantik/struktural seperti 'identifier', 'parameters', dan 'block'.
